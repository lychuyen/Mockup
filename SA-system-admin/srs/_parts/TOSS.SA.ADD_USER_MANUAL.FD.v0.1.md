### Thêm mới User/Tự khai báo

| **Tên chức năng: Thêm mới Người dùng** | |
| --- | --- |
| **Mục đích** | Cho phép user Thêm mới User/ Tự khai báo |
| **Trigger** | Người dùng truy cập vào web FIMS => nhấn phân hệ Quản lý người dùng => nhấn Thêm mới User/ Tự khai báo |
| **Tiền điều kiện** | Người dùng đăng nhập thành công và được phân quyền trên phân hệ Quản lý người dùng |
| **Hậu điều kiện** | Màn hình Thêm mới User/ Tự khai báo hiển thị |
