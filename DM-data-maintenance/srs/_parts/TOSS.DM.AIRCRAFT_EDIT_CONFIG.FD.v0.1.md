### Sửa [chi tiết tàu bay](TOSS.DM.AIRCRAFT_DETAIL_GENERAL.FD.v0.1.md) - tab Aircraft Configuration

| **Tên chức năng**: **Sửa tàu bay - tab Aircraft Configuration n** | |
| --- | --- |
| **Mục đích** | Cho phép user chỉnh sửa thông tin Aircraft Configuration |
| **Trigger** | User click button “Sửa” tại màn hình [chi tiết tàu bay](TOSS.DM.AIRCRAFT_DETAIL_GENERAL.FD.v0.1.md) Aircraft Configuration |
| **Tiền điều kiện** | Người dùng đăng nhập thành công và được phân quyền Sửa tàu bay - tab Aircraft Configuration |
| **Hậu điều kiện** | Sửa thành công, dữ liệu được lưu vào DB |
